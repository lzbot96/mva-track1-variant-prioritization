# Private inputs and configuration

Keep populated inputs outside this package. The placeholders below are schemas, not this case's values. Use original authorized artifacts and reviewer decisions; these examples do not choose findings, terms or scores.

- `MVA_PROJECT_ROOT`: existing controlled run directory, outside code package.
- `MVA_INPUT_VCF`: relative input VCF path, indexed for region selection.
- `MVA_FASTQ_TEMPLATE`: relative filename template, e.g. `data/raw/SAMPLE_L{lane:03d}_R{mate}.fastq.gz`; original pairing script expects lanes 1–4 and mates 1–2.
- `MVA_CLINICAL_DOCX`: relative clinical DOCX path. Extraction preserves paragraphs and tables; curation expects table 1 with one header row, then four columns: feature, source term, HPO identifier, note.
- `MVA_FAMILY_HISTORY_HPO`: reviewer-selected HPO term assigned to family history by the historical transcription rule. No automatic choice.
- `MVA_EXCLUDED_HPO`: reviewer-selected term removed for the third sensitivity ranking. This is separate from family-history assignment.
- `MVA_PANEL_JSON`: relative file containing `{"genes": ["REVIEWER_GENE_SYMBOL"]}`. Supply the reviewed disease-mechanism panel and aliases; do not use the example symbol.
- `MVA_ANCHOR_CANDIDATES`: relative tab-separated file with `name`, `chrom`, `pos`, `ref`, `alt` headers. Supply reviewed SNVs only. Contigs must match the no-chr FASTA, positions are 1-based, and ref/alt are distinct uppercase A/C/G/T bases. Names must be unique tokens. No candidate selection or confidence assignment happens in this script.
- `GNOMAD_HELPER`: optional absolute path to the original compatible helper. When absent the loop uses the reconstructed stdlib public gene API transport. No patient variant/genotype arguments are accepted by that transport.

If supplying curated HPO JSON directly instead of document transcription, required fields are `all_challenge_hpo` (array of reviewed HPO IDs) and `proband_only_hpo` (array of reviewed HPO IDs). Both must be nonempty; the third subset must remain nonempty after the configured exclusion. Existing historical output additionally records `explicit_absent_hpo`, `rows`, and interpretation. Review absence and subject assignment manually.

`download_data.py` requires `sources/dataset_manifest.json` with `repo`, pinned `revision`, and `files`: each file entry supplies `type: "file"`, `path`, `size`, and optionally `lfs.oid` (SHA-256). Recover the original pinned manifest; a current revision is not automatically equivalent. `authenticated_manifest.py` retrieves metadata for that revision using locally configured access. Do not place credentials in any JSON.

The final CSV is deliberately reviewer-authored: no script infers causal ranking, EPCR, phase, or diagnosis from these inputs. Use the [official Track 1 submission template](https://huggingface.co/spaces/SageBio/rare-disease-real-kid-mva-hackathon-2026/blob/main/static/templates/track1_submission_template.csv). The saved local validator expects the candidate CSV at `results/track1_submission_draft.csv` when reproducing its historical checks. It does not call the official evaluator or establish biological correctness.

The gene-specific CDS stage additionally requires `data/references/bub1b_ensembl.json`, a public Ensembl gene object with `start`, `end`, `canonical_transcript` and a `Transcript` array. The selected transcript must supply `id`, `version`, `strand`, an `Exon` array containing `start`/`end`, and a `Translation` object containing `start`/`end`. The saved code assumes the positive-strand chromosome-15 canonical transcript and a 3,153-base CDS; it is not a generic transcript reconstruction engine. The inspected local object identifies GRCh38, ENSG00000156970 version 15 and ENST00000287598 version 11. Its SHA-256 and public reference identity are recorded in `provenance/public_transcript_input.json`; no reference content or case variants are bundled. The historical retrieval command/date was not recovered. Reuse the authorized archived public object or independently obtain and verify an equivalent versioned reference; a present-day canonical-transcript lookup is not guaranteed to match. No live retrieval was tested during this review.

Public frequency acquisition/import: `python scripts/gnomad_public.py --gene REVIEWER_GENE --output data/references/REQUIRED_NAME.json` writes API JSON. Substitute a reviewed public gene symbol and the filename consumed by the summarizer; no patient allele is sent. Alternatively import an authorized saved public response with shape `{"data":{"gene":{"gene_id":"...","variants":[{"variant_id":"public-variant-id","exome":{"ac":0,"an":0,"af":0.0},"genome":null}]}}}`. Public population counts/AF fields may be null; the summarizer keeps missing AF unknown. The loop uses `data/references/gnomad_review_genes/<gene>.json`; its separately acquired initial reference is `data/references/bub1b_gnomad.json`. API transport is reconstructed and untested against the live service; no network call was made during packaging.
