# Dataset and challenge reference

*Rare Disease, Real Kid. The 2026 MVA Hackathon.* Synapse project syn76251147, wiki 642892. [Official Synapse project](https://www.synapse.org/Synapse:syn76251147/wiki/642892). Accessed 24 October 2026. Associated dataset: [SageBio/mva-hackathon-2026-data](https://huggingface.co/datasets/SageBio/mva-hackathon-2026-data).

The Track 1 analysis used the authorized challenge dataset and public reference resources. This repository distributes method code and synthetic tests, not controlled source data or genome-carrying derivatives. Reference versions and reproducibility limits are documented in WORKFLOW.md and the provenance files.
